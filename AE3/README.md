# ACTIVIDAD 3: COMPARACIÓN DE DATOS CLIMATICOS

## Medellín (Colombia) y Madrid (España)
**Periodo de análisis:** Enero a diciembre de 2023.

## 1. Introducción

Este analisis de datos climaticos permite identificar comportamientos, tendencias y diferencias entre distintas regiones geográficas. En esta actividad se realiza una comparación entre Medellín, Colombia, y Madrid, España, utilizando información climática correspondiente al año 2023.
Para desarrollar el análisis se emplean las bibliotecas Pandas, NumPy y Matplotlib de Python. Se estudian dos variables principales: la temperatura máxima diaria y la precipitación diaria.
A través de la exploración, limpieza, procesamiento estadístico y representación gráfica se busca comprender las diferencias y semejanzas climáticas entre ambas ciudades.

## 2. Objetivo

Comparar el comportamiento de la temperatura máxima diaria y la precipitación de Medellín y Madrid durante el año 2023, aplicando herramientas de análisis y visualización de datos con Python.

Se plantea que Medellín presenta temperaturas máximas más estables durante el año, mientras que Madrid muestra una mayor variación térmica entre las estaciones. También se espera encontrar diferencias en la distribución y acumulación de las precipitaciones.
